Locations

VERSION 1.0

2. Locations & Storage Architecture

2.1 Locations SOP

  1. Go to **Master Data > Locations**.
  2. Click **Create New**.
  3. Fill **Storage Code** (e.g., `WH-A`) and **Name**.
  4. Select **Type**. Click **Save**.

2.2 Racks SOP

  1. Go to **Master Data > Racks**.
  2. Select Parent Location First.
  3. Enter **Rack Code** (e.g., `R-A1`).
  4. Click **Save**.

Configuration

VERSION 1.0

3. Asset Configuration Masters

Before creating tools, you must define these classification attributes.

3.1 Tools Types

  1. Go to **Master Data > Tool Types**.
  2. Click **Add New**.
  3. Enter Name (e.g., *Power Tools*, *Safety Gear*).
  4. **Is Consumable?**: Check only if items are single-use (e.g., Gloves).

3.2 Material Groups

  1. Go to **Master Data > Material Groups**.
  2. Define grouping logic (e.g., *Electrical*, *Mechanical*).

3.3 Manufacturers

  1. Go to **Master Data > Manufacturers**.
  2. Enter Brand Name (e.g., *Bosch*, *Makita*).
  3. Enter Support Contact (Optional).

3.4 Calibration Vendors

  1. Go to **Master Data > Vendors**.
  2. Enter **Company Name** and **Service Capability**.
  3. Technical Note: Used in Calibration Transactions.

Asset Registry

VERSION 1.0

4. Tools Asset Registry

4.1 Creating New Asset

  1. Go to **Master Data > Tools**.
  2. Click **Create New**.
  3. Barcode Scanning: Click field and scan physical tag.
  4. Select **Type**, **Group**, **Brand** from dropdowns (configured in Chap 3).
  5. Select **Location** & **Rack**.
  6. Note: Initial status is always **Available**.
SQL Schema
CREATE TABLE tools (serial_number VARCHAR(255) UNIQUE, status ENUM(...));

Transactions

VERSION 1.0

5. Loan Management

5.1 Issue Loan

  1. Menu: **Loan Transaction > New Loan**.
  2. Search Borrower by **NIK**.
  3. Scan Tool. System validates `status == 'available'`.
  4. Submit. Tool Status -> `in_use`.

5.2 Return Loan

  1. Menu: **Loan Transaction > List**.
  2. Find active loan. Click **Return**.
  3. Tool Status -> `available`.

Mutations

VERSION 1.0

6. Asset Mutation (Transfer)

Use this to permanently move assets between Warehouses or Racks.

6.1 Mutation SOP

  1. Menu: **Transaction > Mutation**.
  2. Select **Tool** (Must be Available).
  3. Select **Origin** (Auto-filled) and **Destination Location**.
  4. Select **Destination Rack**.
  5. Submit. System updates `location_id` on `tools` table.

Maintenance

VERSION 1.0

7. Calibration & Maintenance

7.1 Send to Calibration

  1. Menu: **Transaction > Calibration**.
  2. Select Tool and **Vendor**.
  3. Tool Status -> `calibration`.

7.2 Receive from Calibration

  1. Find active calibration ticket. Click **Receive**.
  2. Upload **Certificate** (PDF/JPG).
  3. Set **Next Due Date** (Critical for alerts).
  4. Tool Status -> `available`.

9. Administrative Guide (Tinker & Console)

Use these commands for system maintenance and disaster recovery.

9.1 Essential Console Commands (CMD / Terminal)

Run these commands in the project root directory (e.g., C:\xampp\htdocs\SystemGudang_Lbe).

Server & Setup
# Start Local Server
php artisan serve

# Fix Image/Logo Not Loading
php artisan storage:link
Database Maintenance
# Run Database Updates (Migrations)
php artisan migrate

# [WARNING] Reset Database (Deletes All Data!)
php artisan migrate:fresh --seed
Cache & Performance (Fix weird glitches)
php artisan optimize:clear
php artisan config:cache
php artisan route:cache
php artisan view:clear
Automation (Scheduler)
# Run Calibration Alert Checks manually
php artisan schedule:run

10. Technical Architecture: Service Route Map

This section maps every URL Endpoint to its Backend Controller ("What connects to where"). Use this for debugging 404 errors or tracing logic flows.

10.1 Authentication & Core

URI Endpoint HTTP Method Controller :: Method Description
/login GET LoginController::showLoginForm Show Entry Page
/login POST LoginController::login Process Credentials
/logout POST LoginController::logout Terminate Session
/dashboard GET DashboardController::index Main Command Center

10.2 Master Data Routes

URI / Resource Controller Key Methods
/locations LocationsController index, store, update, destroy
/racks RackController store, update (Child of Location)
/tools ToolsController store (Creates Asset), show (Detail)
/tools-type ToolsTypeController Category Definitions
/manufacture ManufacturerController Brand Management
/employee EmployeeController Borrower Database

10.3 Transactional Logic Flow

URI Endpoint Controller :: Method Logic Hook
/loan/items/{id} LoanController::getAvailableItems AJAX: Checks 'Available' status
/loan (POST) LoanController::store Locks Asset (Status -> In Use)
/loan/{id}/return LoanController::processReturn Unlocks Asset (Status -> Available)
/damage-lost (POST) DamageLostController::store Flags Asset (Status -> Loss/Damage)
/mutation (POST) MutationController::store Updates location_id permanently

10.4 Reporting & Analytics

URI Endpoint Controller :: Method Output
/reporting-center ReportingCenterController::index UI Filter Selection
/reporting-center/export ReportingCenterController::exportExcel .XLSX File Download
